## Problèmes rencontrés et solutions
- Problème : la caméra ne renvoyait aucune image (`frame` vaut `None`).
  Solution : autorisation de la caméra pour le terminal, vérification de l'indice de la caméra (la Continuity Camera de l'iPhone peut prendre l'indice 0) ; le code vérifie maintenant `ret` avant de lire l'image.
- Problème : `mp.solutions` introuvable avec Python 3.14.
  Solution : environnement recréé avec Python 3.11 et versions fixées (`mediapipe==0.10.14`, `scikit-learn==1.4.1.post1`, `numpy==1.26.4`).
- Problème : l'installation de Streamlit a modifié des versions (`protobuf`, NumPy), ce qui a provoqué les erreurs `GetPrototype` et `numpy.dtype size changed`.
  Solution : réinstallation des versions compatibles (`protobuf==4.25.3`, NumPy 1.26.4, scikit-learn 1.4.1.post1, opencv-python 4.9.0.80, mediapipe 0.10.14). [À confirmer une fois le test relancé.]
- Problème : le `.gitignore` du dossier `model/` ne protège pas la racine du projet.
  Solution : création d'un `.gitignore` à la racine (`venv/`, `__pycache__/`, `*.db`, `.env`).
